# Fiscoo: installer

Questo repository contiene solo i file di installazione di Fiscoo (Mac con chip Apple, Mac Intel, Windows) e gli aggiornamenti. Il codice sorgente non è qui.

Per installare Fiscoo usa la pagina https://fiscoo.pages.dev/scarica/ con il codice personale del tuo studio.

Impronte SHA-256 di ogni versione: file `SHA256SUMS.txt` del release.
